# Campus Store Management System

## About the Project
Campus Store Management System is a web-based application
developed to manage the operations of a college campus store.

The system manages products, categories, pricing, discounts,
billing, transactions and audit records.

## Technologies Used
- C++ (Object-Oriented Programming/ Procedural Oriented Programming)
- HTML
- CSS
- JavaScript
- SQLite
- GitHub
- VS Code

## Main Modules
1. Authentication
2. Dashboard
3. Product Management
4. Category Management
5. Discount and Coupon Management
6. Billing and Invoice
7. Reports and Audit

## OOP Concepts
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Function Overloading
- Constructors
- Static Members
- Friend Functions
- Operator Overloading

## Project Structure
- backend: C++ implementation
- frontend: Website interface
- tests: Test cases
- docs: Project documentation
- procedural-version: Procedural baseline

## Installation
1. Clone this repository.
2. Install the required C++ compiler.
3. Configure the SQLite.
4. Build the backend.
5. Start the backend server.
6. Open the website in a browser.
